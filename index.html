它解决什么问题

PROBLEM

工时、周报、待办、台账、移交、代码和工单，原来散落在不同页面。ZJAI 把这些重复动作做成当前页面上的入口，仍使用你已经登录的账号。

原来：入口分散

  • 同类待办、工时、周报和台账要分别找入口。
  • 已发协同、项目移交和代码扫描不在同一处。
  • BUG 工单上的人员和源码冲突要手工核对。
→

现在：一个悬浮入口

  • 协同首页用扇形入口处理待办、工时、需求和已发。
  • 周计划、台账、移交、工单和冲突检测留在对应业务页。
  • 代码合规扫描放在 CTP-Studio 首页。
协同功能用在已登录的 xt.seeyon.com。代码合规扫描用在 studio.kk.seeyon.com。两边都使用当前登录态，不另建账号。

它怎么做到的

HOW IT WORKS

扩展按页面注入。协同首页走悬浮入口；周计划、台账、移交和工单页在识别到对应页面后出现自己的入口；代码扫描只出现在 CTP-Studio。

① 打开首页

打开对应页面

协同首页、业务单据页，或 CTP-Studio 首页。

→
② 选择入口

点该页入口

首页是扇形菜单；其他页面是该功能自己的悬浮球或菜单。

→
③ 当前页完成

查询或处理

结果留在当前页，详情仍打开原来的协同页面。

不改 OA 服务器上的业务代码。卸载或停用扩展后，协同本身的菜单和列表仍按原来的方式使用。

全部功能

ALL FEATURES
☰

批量处理

覆盖周计划、工时单、项目周报、绩效考核、前置评估、客开作业单。

⌕

已发查询

按标题关键词查当前账号已发协同。留空则查最近已发。

◷

工时签卡

查看本人最近工时和签卡。工时登记详情页也可从右下入口进入。

✎

提需求

在扩展页填写需求、联系人和在线文档，提交到既有钉钉机器人。

周

周工作计划汇总

识别周计划页后，把上周工作明细汇总到上周总结，也可手动重算。

账

项目台账检查

在项目台账页检查关键字段和明细是否完整，延期项红色标出。

移

项目移交会议纪要

在项目移交流程页读取字段，核对后生成已填充的会议纪要 DOCX。

码

代码合规扫描

在 CTP-Studio 首页扫描浙江军团、浙江大区、江浙大区项目的代码。

人

工单速配

BUG 分配节点识别并推荐工程师，减少手工对名单。

冲

客开冲突雷达

在工单详情页检查客开源码和补丁包是否冲突。

标

自定义入口图标

扩展图标可上传、圆形裁剪，并保留最近五次，方便切换。

30 秒安装

INSTALL
先下载扩展压缩包

下载 zjai-browser-plugin-v3.4.15.zip，解压后选中含 manifest.json 的文件夹。

下载 v3.4.15 压缩包
1

打开扩展页

Chrome 输入 chrome://extensions，Edge 输入 edge://extensions

2

开启开发者模式

打开页面右上角的「开发者模式」开关

3

加载文件夹

选择「加载已解压的扩展程序」，选中解压后的文件夹

4

刷新协同

刷新已登录的 OA 首页，悬浮主入口即可使用

升级时建议先移除旧的已解压版本，再加载新目录。只改了脚本时，也可以在扩展卡片上点刷新后，再刷新 OA 页面。
