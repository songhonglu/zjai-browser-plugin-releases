它解决什么问题

PROBLEM

协同首页上，同类待办要逐条打开，已发记录要靠系统列表来回翻。ZJAI 把这些高频动作收进当前页面的悬浮入口。

原来：入口分散

  • 周计划、工时单、项目周报等要一条条点开处理。
  • 查自己发出的协同，只能在系统已发列表里翻。
  • 工时核对和提需求不在同一个入口。
→

现在：一个悬浮入口

  • 扇形入口里直接进入批量处理、工时签卡、提需求、已发查询。
  • 已发查询按标题关键词分页，能跳到指定页。
  • 列表给出标题、当前待办人和发起时间。
适用页面是已登录的 xt.seeyon.com。扩展使用当前账号自己的协同数据，不另外建账号。
2

它怎么做到的

HOW IT WORKS

扩展注入已登录的协同页面。你点悬浮入口后，它用当前登录态调用协同接口，把结果画在页面自己的面板里。

① 打开首页

已登录协同

在 xt.seeyon.com 首页看到 ZJAI 悬浮球。

→
② 选择入口

扇形菜单

批量处理、工时签卡、提需求、已发查询。

→
③ 当前页完成

查询或处理

结果留在当前页，详情仍打开原来的协同页面。

不改 OA 服务器上的业务代码。卸载或停用扩展后，协同本身的菜单和列表仍按原来的方式使用。

30 秒安装

INSTALL
先下载扩展压缩包

下载 zjai-browser-plugin-v3.4.15.zip，解压后选中含 manifest.json 的文件夹。

下载 v3.4.15 压缩包
1

打开扩展页

Chrome 输入 chrome://extensions，Edge 输入 edge://extensions

2

开启开发者模式

打开页面右上角的「开发者模式」开关

3

加载文件夹

选择「加载已解压的扩展程序」，选中解压后的文件夹

4

刷新协同

刷新已登录的 OA 首页，悬浮主入口即可使用

升级时建议先移除旧的已解压版本，再加载新目录。只改了脚本时，也可以在扩展卡片上点刷新后，再刷新 OA 页面。
